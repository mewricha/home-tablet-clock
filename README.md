# นาฬิกาที่บ้าน

เว็บนาฬิกาสำหรับแท็บเล็ต Android แนวนอน แสดงเวลาท้องถิ่นตัวหนาขนาดใหญ่พร้อมวินาทีขนาดเล็ก วันที่ภาษาไทยและอังกฤษ อากาศใกล้ตำแหน่งปัจจุบัน ค่า PM2.5 และเวลาปารีสพร้อมชื่อไทย–อังกฤษและธงชาติ แถบบนแบ่งเป็นสามส่วนเท่ากัน รวมถึงข้อมูลดวงอาทิตย์ ดวงจันทร์ ข้างขึ้นข้างแรม และวันพระ พร้อมฉากอากาศเคลื่อนไหวเบา ๆ บนพื้นหลังสีดำ

สีเวลาปารีสเปลี่ยนตามตำแหน่งดวงอาทิตย์: เหลืองอ่อนและสัญลักษณ์ ☀ เมื่อเป็นกลางวัน ฟ้าอ่อนและสัญลักษณ์ ☾ เมื่อเป็นกลางคืน

## ลง GitHub Pages

อัปโหลด `index.html`, `suncalc.js`, `SUNCALC-LICENSE.txt`, `thai-lunar.js` และ `THAI-LUNAR-LICENSE.txt` ไปไว้ที่รากของ [repository นี้](https://github.com/mewricha/home-tablet-clock) แล้วเปิด [หน้าเว็บ](https://mewricha.github.io/home-tablet-clock/) บนแท็บเล็ต รูปธงรวมอยู่ใน `index.html` แล้ว ส่วนไฟล์ `preview.html` ใช้ดูตัวอย่างในเครื่องเท่านั้น

ครั้งแรกให้แตะ **เริ่มใช้งานและเปิดตำแหน่ง** แล้วอนุญาตตำแหน่งในเบราว์เซอร์ หากไม่ต้องการใช้ตำแหน่ง ให้เลือกเมืองด้วยตนเองจากหน้าตั้งค่า

ข้อมูลอากาศและ PM2.5 ใช้ [Open-Meteo](https://open-meteo.com/) โดยค่า PM2.5 เป็นค่าประมาณจากแบบจำลอง [CAMS](https://atmosphere.copernicus.eu/) ในระดับพื้นที่ สีและแถบระดับอิงดัชนี US AQI สำหรับ PM2.5 ควรมีอินเทอร์เน็ตสำหรับการอัปเดต ส่วนเวลายังทำงานได้เมื่อออฟไลน์ เว็บจะเก็บข้อมูลอากาศล่าสุดไว้ในเบราว์เซอร์ของแท็บเล็ต

เวลาขึ้นและตกของดวงจันทร์กับเปอร์เซ็นต์พื้นผิวที่สว่างคำนวณในเครื่องด้วย [SunCalc](https://github.com/mourner/suncalc) โดยมีไฟล์สิทธิ์การใช้งานใน `SUNCALC-LICENSE.txt` กรุณาอัปโหลด `suncalc.js` และไฟล์สิทธิ์การใช้งานไปพร้อม `index.html`

ข้างขึ้นข้างแรม ป้ายวันพระ และวันพระครั้งถัดไปคำนวณในเครื่องตามปฏิทินจันทรคติไทยด้วย `thai-lunar.js` ที่ดัดแปลงจาก [thailunar](https://github.com/KranaxALT/thailunar) ซึ่งสืบจาก pythaidate ทั้งคู่ใช้สิทธิ์ MIT และรวมไว้ใน `THAI-LUNAR-LICENSE.txt` วันพระหมายถึงขึ้น 8/15 ค่ำ แรม 8 ค่ำ และวันสุดท้ายของเดือนจันทรคติ โดยอิงวันที่ของประเทศไทย ตรวจเทียบวันพระปกติทุกวันในปี 2569 กับ [Thai PBS](https://www.thaipbs.or.th/now/content/3498) แล้ว ทั้งนี้วันเข้าพรรษาแรม 1 ค่ำแยกจากป้ายวันพระตามเกณฑ์ปกติ ปีอื่นยังไม่ได้ตรวจเทียบทั้งปี

การคงหน้าจอเปิดใช้ Screen Wake Lock ในเบราว์เซอร์ที่รองรับและต้องเปิดจาก HTTPS หากแท็บเล็ตยังดับจอ ให้ตรวจการตั้งค่าเวลาพักหน้าจอของ Samsung และลดความสว่างให้พอดีกับการใช้งานระยะยาว
