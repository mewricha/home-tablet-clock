# นาฬิกาที่บ้าน

เว็บนาฬิกาสำหรับแท็บเล็ต Android แสดงวันที่ เวลาท้องถิ่น อากาศใกล้ตำแหน่งปัจจุบัน และเวลาปารีส พร้อมฉากเคลื่อนไหวเบา ๆ

## ลง GitHub Pages

1. สร้าง repository ใหม่แบบ Public บน GitHub
2. อัปโหลด `index.html` ไปไว้ที่รากของ repository
3. เปิด **Settings → Pages** แล้วเลือก **Deploy from a branch**, branch `main`, โฟลเดอร์ `/ (root)`
4. เปิดลิงก์ HTTPS ที่ GitHub Pages แสดงบนแท็บเล็ต

ครั้งแรกให้แตะ **เริ่มใช้งานและเปิดตำแหน่ง** แล้วอนุญาตตำแหน่งในเบราว์เซอร์ หากไม่ต้องการใช้ตำแหน่ง ให้เลือกเมืองด้วยตนเองจากหน้าตั้งค่า

ข้อมูลอากาศใช้ [Open-Meteo](https://open-meteo.com/) และควรมีอินเทอร์เน็ตสำหรับการอัปเดต ส่วนเวลายังทำงานได้เมื่อออฟไลน์ เว็บจะเก็บข้อมูลอากาศล่าสุดไว้ในเบราว์เซอร์ของแท็บเล็ต

การคงหน้าจอเปิดใช้ Screen Wake Lock ในเบราว์เซอร์ที่รองรับและต้องเปิดจาก HTTPS หากแท็บเล็ตยังดับจอ ให้ตรวจการตั้งค่าเวลาพักหน้าจอของ Samsung และลดความสว่างให้พอดีกับการใช้งานระยะยาว
